# Evolution-Snake-Game-with-JavaScript
An evolving Snake game built with HTML5 Canvas and JavaScript where the snake transforms into different creatures and objects as the score increases.

Description:

Evolution Snake is a modern twist on the classic Snake game. As players collect food and increase their score, the snake evolves through different stages, changing its appearance and environment. The game also introduces hazards, power-ups, and dynamic maps to make gameplay more engaging.

Features:
🧬 Evolution system – Snake changes form as score increases
🌍 Dynamic maps – Grass, road, jungle, volcano, and space environments
💣 Bomb hazards – Lose a heart if you hit a bomb
✂️ Scissors power-up – Cuts your snake length in half
🍎 Apple power-up – Restores health
❤️ 3-life system
🎵 Background music
⚡ Fast and lightweight browser game

Gameplay:
Use Arrow Keys to move the snake
Eat food to increase your score
Avoid bombs and walls
Collect power-ups to survive longer
Watch the snake evolve into new forms

Evolution Stages:
The snake evolves as your score increases:
🐍 Snake
🚗 Car
🐯 Tiger
🦖 Dinosaur
📱 Phone
🦅 Eagle
🐉 Dragon
🚀 Rocket
🤖 Robot
🌋 Volcano

Technologies Used:
HTML5
CSS
JavaScript
Canvas API

How to Run:
Download the repository
Open index.html
Play directly in your browser
